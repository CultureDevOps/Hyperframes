LE PATTERN MVC

Model • View • Controller

Trois responsabilités. Une application plus claire.

Les trois rôles
M

Model

Données et règles métier

V

View

Présentation à l'utilisateur

C

Controller

Reçoit et coordonne les actions

1 • L'utilisateur agit
● ● ●   boutique.exemple / produits

Bienvenue dans la boutique !

Voir les produits →

Le navigateur envoie une requête HTTP.

2 • Le Controller

Controller

// GET /produits

function listeProduits() {
  return produitService.lister();
}

Il reçoit la requête et déclenche le traitement.

3 • Le Model

Model

// Données et logique métier

produits = [
  { nom: "Clavier", prix: 49 },
  { nom: "Souris", prix: 29 }
]

Il fournit les données et applique les règles métier.

4 • La View

View

● ● ●   boutique.exemple / produits

Nos produits

⌨️ Clavier — 49 €

🖱️ Souris — 29 €

Elle affiche les données à l'utilisateur.
