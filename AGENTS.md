# Instructions for Codex — Hyperframes motion design

This repository hosts reusable motion-design compositions for Culture DevOps only.

## Principles
- Prefer reproducible, code-driven animations and deterministic renders.
- Keep Culture DevOps assets and compositions organized by campaign or format.
- Do not commit credentials, API keys, generated videos, or large binaries.
- Before using HyperFrames CLI commands or APIs, inspect its current upstream documentation; do not assume an unverified CLI interface.
- Favor accessible typography, 16:9 compositions, and clear pacing.
- Keep source assets and licensing information documented.

## First milestone
1. Verify upstream HyperFrames installation and rendering instructions.
2. Bootstrap the project using the documented toolchain.
3. Implement a 10-second Culture DevOps intro: dark background, subtle particles, logo reveal, then “Simplifiez – Automatisez – Innovez”.
4. Add preview and rendering instructions, and a CI workflow only after commands are validated.
5. Document any dependencies and limitations.

## Review checklist
- Confirm dependencies and licenses.
- Ensure preview works before rendering.
- Keep outputs out of version control.
- Avoid introducing deployment secrets.
